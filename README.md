# python-file-renamer

A simple and flexible Python script to rename multiple files at once.

## Features
- Rename files based on:
  - Alphabetical order (A-Z or Z-A)
  - Date created
  - Date modified
- Choose ascending or descending numbering
- Custom prefix
- Skips files if the new name already exists
- Works on Windows

## How to use
1. Run the script
2. Enter the folder path
3. Choose the sorting method (1-6)
4. Enter a prefix for the new names
5. Choose numbering direction (ascending or descending)

## Example
old names:          new names:

img_a.jpg      →    photo 1.jpg

img_b.jpg      →    photo 2.jpg

img_c.jpg      →    photo 3.jpg
